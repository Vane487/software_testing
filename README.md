# Software Testing Lab 2

Лабораторна робота №2 з модульного тестування та ізоляції залежностей для варіанта 04
«Оренда автомобілів».

## Структура

- `src/main/java/CarRentalService.java` — наданий production-код без виправлення навчальних дефектів.
- `src/test/java/CarRentalServiceTest.java` — JUnit Jupiter Test Suite із Mockito.
- `pom.xml` — конфігурація Maven.

## Запуск

Потрібні Java 17 і Maven.

```bash
mvn test
```

## Покриття вимог лабораторної

- 10 тестових методів;
- позитивні та негативні бізнес-сценарії;
- параметризований тест із чотирма наборами невалідних даних;
- State-Based Testing для сум, статусів і складових результату;
- Interaction-Based Testing для викликів залежностей;
- перевірка аргументів `RentalRepository.save` через `ArgumentCaptor`;
- Test Doubles для `FleetAvailability`, `DriverHistory` і `RentalRepository`;
- два сценарії винятків від зовнішніх залежностей.

## Виявлені розбіжності зі специфікацією

| Специфікація | Фактична реалізація |
| --- | --- |
| Вік 21–75 включно | Максимальний вік 74 |
| Знижка діє від 7 діб | Знижка діє лише після 7 діб |
| Історія потрібна для молодого водія АБО premium-авто | Історія перевіряється лише для молодого водія І premium-авто |

Тестові методи, що фіксують фактичну поведінку цих навчальних дефектів, мають суфікс
`_counterRequirement`. Production-код навмисно не виправлявся.
